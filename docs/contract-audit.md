# 当前合同审计

## 任务与边界

审计基线为 Windows v1.0.6 的 `1b903867027627b17a5fee2ce82ad4d4cf52074c`，初始工作区干净，共 93 个受版本控制文件。覆盖项目规则、README/安装说明、架构/交接/历史文档、Python 入口与推理/导出/设置、测试、BAT、PowerShell、Inno/PyInstaller、依赖和发布收据；图片/基准 JSON 作为证据资产，不解释为当前产品规则。

目标是以当前实现统一合同，消除可安全处理的重复定义与漂移。模型选择、默认设置、QSettings 身份/键、推理策略、停止、输出内容/命名、现有 UI 配色与布局保持；不操作真实媒体，不删除输出/模型，不调用真实文本 API，不重发布已有安装包。
