# 南枫转写 Windows v1.0.2

## 本次更新

- 新增可持久化的完成提醒设置：完成提示音、完成提示，以及完成后自动打开目录。
- 全部成功时，可自动在资源管理器中定位并选中本批次最近完成的实际导出文件。
- 完成提示音使用短促低音量双音；成功与失败采用不同音调，可在设置中关闭。
- 音频提取失败现在会区分无音轨、源文件不存在、权限不足和媒体损坏等原因。
- 无音轨、静音或仅含画面的视频会标记为“无文字”，避免误判为 GPU 或模型异常。

## 安装

直接下载 `NanfengTranscriber_Windows_v1.0.2_Setup_*.exe`，双击安装。

首次使用某个 Whisper 模型需要联网下载；模型会保存在本机用户缓存，后续启动自动复用。Release 仅提供安装程序本体，安装说明以 README 的中文内容为准。

## 验证

- 完整自动化回归、源码编译、PyInstaller 目录版启动和 Inno Setup 安装生命周期验证均在发布前执行。
- 安装包未进行商业代码签名；Windows SmartScreen 可能显示未知发布者提示。
