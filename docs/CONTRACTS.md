# 当前软件合同

本页按当前代码归纳产品行为；版本取 `app/assets/product.json`，证据见 [当前状态](PROJECT_STATUS.md)。历史记录见 [HISTORY.md](HISTORY.md)。新增或改动合同必须同步所有者、消费者和行为检查。条目、源码/测试路径、文档角色由 [contract-registry.json](contract-registry.json) 索引；该索引不再复制规则正文。

维护顺序：先核对实现与适用证据 → 修改本页对应 C 编号 → 同步索引的所有者/测试 → 更新 README 使用说明及状态/交接 → 运行合同门禁和受影响回归。历史报告、已发布收据和旧截图不覆盖当前行为；未实现或未验证项只写入审计缺口。改变功能必须另有明确任务，不用文档消除实际缺陷。

## C01 产品与队列入口

- Windows 本地优先批量音视频转写，另提供用户选择后调用的百炼云端模式；支持添加文件、递归添加文件夹及拖放。支持格式由 `SUPPORTED_EXTENSIONS` 定义，不提供媒体下载或账号登录。
- 主入口 `start.py`，推荐 BAT `启动最新界面_Windows.bat`；`--check` 只验证启动依赖。其他源码 BAT 保留兼容，名称中的“测试设置”仍打开工作台。
- 可启动的勾选项目是等待、失败、已停止和无文字；完成/已存在不是再次启动候选。全选/反选可能勾选已存在项，但不会因此重新启动它。
- 成功转写并保存历史后立即从队列隐藏，批次线程结束后清除对应队列记录，完成统计和输出定位仍计入成功项。历史保存失败保留原队列项，打开历史重试保存成功后移除；失败、无文字、已停止及已存在项保留。
- 队列不持久化。一个批次拥有一个 `TranscriptionSession`，逐项处理；停止阻止后续项。模型下载/加载等阻塞阶段不承诺立即返回，独立 Qwen 进程只由本任务终止。

## C02 模型与兼容

| 用户模式 | 识别模型 | SRT |
|---|---|---|
| 中文精确 | Qwen3-ASR-1.7B | 导出时调用 Qwen3-ForcedAligner-0.6B |
| 通用快速 | Whisper large-v3-turbo / faster-whisper | 默认词时间戳；设置可启用上述精确对齐器 |
| 高精度 Qwen | qwen-audio-3.1-asr-flash-filetrans | 百炼句级时间戳，无需本地对齐器 |
| 低成本 Paraformer | paraformer-v2 | 百炼句级时间戳，无需本地对齐器 |

共有两种本地模式与两种百炼云端模式；本地仍只有两套识别权重和一个固定对齐器。旧 `base/small/medium/large-v3` 及 `turbo` 输入映射到快速模式；`qwen3-asr` 映射中文精确。旧名称在兼容测试中出现，不代表仍可选。

新设置默认中文精确、中文、GPU 快速；旧未知模型设置回退通用快速，旧 GPU 优先显示值回退 GPU 快速。主模式框上方显示中文名称，下方显示真实模型名；队列表格模式框使用中文名及悬停说明。

## C03 云端转写协议

- 对齐手机版 `a2cd59548ef1ca0da36d1856930fceba24af275a` 的 DashScope 文件转写：固定北京端点 `https://dashscope.aliyuncs.com/api/v1/`，临时 OSS 上传、异步提交、轮询与真实句级时间戳；沿用原文、历史、TXT/MD/SRT/DOCX 导出链路。
- API Key 在设置“云端转写 API”中维护，用 Windows DPAPI 绑定当前用户加密保存；打开设置自动填入，默认掩码，白底输入框内右侧眼睛切换显示。`DASHSCOPE_API_KEY` 环境变量优先。取消设置不保存，空白保持原值，清除需显式勾选。
- 按2026-10-20用户要求，选择云端模型后点击开始直接运行，不再弹出上传/费用二次确认；设置和模型说明保留音频上传到百炼及可能计费的说明，缺少或无法读取Key时仍阻止启动。请求在转写工作线程内执行；API Key 不进入文稿、日志、任务恢复文件或 API 参数 repr。
- 混合本地/云端队列中，GPU 检查切换 CPU 仅更新计算模式，保留已配置的云端 Key、恢复目录与其他批次选项；不额外弹出云端启动确认。
- 任务编号在轮询前持久化；重试优先恢复任务，完成结果复用。提交响应丢失时保留不确定标记，阻止自动重发；明确HTTP拒绝可重试。结果过期时提示再次计费，不自动创建新任务。停止仅停止本地等待，已提交任务仍可能计费。
- 云端 API 网络调用使用显式超时、上传流式读取、响应上限和地址校验；上传与结果下载不携带百炼 API Key，结果只允许官方 OSS HTTPS 地址。

### 本机调用记录

- 设置“云端转写 API”下方提供“调用记录”，按完整文件汇总重试，后台分段不单列。兼容依据为手机版 `NanfengTranscriber-Android@0e0d7896552566d262c3f94f2c77ea8a0a64bae4` 的 `AsrInvocationLedger`、`AsrInvocationHistoryScreen`、`AsrCostEstimator` 与 `TranscriptionTaskRunner`。
- 仅实际尝试网络请求的云端任务写入不可覆盖的本地事实；本地转写、预检拒绝、完成缓存命中和取消不写。保存失败不丢弃转写结果。队列文件有稳定任务身份，重试沿用；旧空身份按记录ID分组。
- 独立 `asr_invocations.sqlite3` 位于历史根目录，不迁移或改写原历史库。只保存文件显示名、任务身份、服务商/模型、完成时间、耗时、请求数、服务端计费音频时长、状态、可空Token、价格版本/币种/估算及白名单错误码；不保存密钥、原始响应、音频、转写正文或完整源路径。
- 列表按最新完成时间排序，每文件展示最新状态/模型/时间/错误，累加尝试耗时和分段数；Token和费用只有全部尝试提供时才求和，任何缺失保持未知。金额显示“费用估算：≈ ¥…（估算）”；未知或非CNY显示“费用估算：暂无费用数据”，不当成已结算账单。
- 沿用手机带版本的本地估价：Qwen `qwen-audio-3.1-filetrans-cn-token-2026-10-09-v1`，每输入/输出Token分别0.8/2.7微元；Paraformer `paraformer-v2-cn-duration-2026-10-09-v1`，服务端报告音频每毫秒0.08微元。Decimal四舍五入到微元，Qwen任一Token缺失、Paraformer时长缺失或为零均不估算；不以本地媒体时长补造用量。
- 入口文件数、列表查询在后台运行；虚拟列表仅绘制可见行，几何布局分批执行，刷新保留滚动位置，窗口关闭后不更新UI；不增加手机没有的删除、导出、筛选功能。

## C05 输出与已有结果

- 基础目录在软件指定路径与每个源文件父目录之间二选一；子目录开关独立生效，共四种组合。不开子目录时直接写入基础目录。
- 文件名和子目录名都使用 `safe_output_stem`，非法字符清理，超长名称裁剪并附短哈希；“视频同名”不承诺逐字保留非法/超长名称。
- GUI 至少选一个格式，否则阻止启动。已有结果检查只检查本次选中的后缀；任一已存在便询问，Yes 覆盖并继续，No 跳过该项目并继续剩余队列。
- TXT/Markdown 原文采用可读片段合并；Markdown 原文带时间表格。润色后 TXT/Markdown/DOCX 使用处理后文字，SRT 始终使用原始识别片段及时间线。
- SRT 以 24 字、5 秒、停顿和句末阈值拆分，排序并裁剪相邻重叠，过滤无有效时长的条目。没有词对齐时只在原片段范围内比例分配，不宣称精确逐词时间。
- 无识别片段以“无文字/失败说明”反馈，不生成伪文字。导出不是事务：后续格式失败时先前已写文件可能留存；不以整体失败为由自动删除真实输出。
- 定位优先已生成文件，其次源媒体。结束自动定位只在有成功且无失败、无文字或停止时执行，选中最近结果。主动停止不播放完成音。

## C06 异步与流畅度边界

- 已初始化的 SQLite v1 库在普通读取时不写 schema/结构版本；首次建库仍初始化 WAL、表和版本。列表查询/失效计数在后台执行，重复请求合并，只应用最新结果。SQLite锁等待上限200ms；该上限不等于整个操作耗时上限。转写完成归档和其失败重试由单一后台写者串行完成，保存成功才隐藏队列项。
- 历史详情读取、文件检查、全选、编辑保存、导出、删除、清理和重定位通过单路后台动作池执行；导航读取合并为当前及最新请求，迟到结果不得覆盖后续页面。读取期间旧编辑器暂时禁用，失败恢复；写操作仍完成后回报，不把关闭或取消当作保存成功。历史入口不构造播放器，第一次媒体核对才初始化原生媒体对象。
- 历史卡片每轮最多添加8张，列表只取240字预览，全文搜索、详情、复制和导出仍使用完整文字。长文稿及字幕按时间预算分批填充，字幕定位使用二分索引。筛选/缩放取消旧渲染；缩略图固定2路非页面子线程池，取消后也通知完成，避免页面析构等待线程池。
- 文件/目录发现及路径规范化在后台执行，GUI每轮最多4行且预算8ms；遍历及插行可取消，时长探测最多2路且FFprobe超时5秒。迟到结果使用持久索引保护；导入、预检和运行互斥，预检返回核对包含任务身份的队列快照，不能只依赖行号。
- 启动依赖/GPU/既有输出检查、输出目录创建、文件定位使用固定2路后台I/O池，不在GUI进行慢盘访问。选项使用内存快照与单路合并写者，持久化失败保留待写项并提示；关闭前提供重试、放弃或取消，不将排队写入说成已保存。
- 下拉框仅在自身弹出期间注册全局事件过滤器；普通队列行不增加全应用事件成本。工作线程进度最多每100ms一次，状态切换和最终结果立即通知。日志使用有界后台队列，完成声音使用后台单通道；设置、关于、完成弹窗退出后释放。
- 关闭请求取消本窗口拥有的转写、安装及只读任务，GUI通过定时器等待写入和线程实际退出；收到finished信号后先以wait(0)确认退出才析构QThread，不在GUI阻塞等待。取消关闭可恢复历史页面。原生模型加载、当前网络请求及操作系统文件调用仍可能等待底层返回，界面须持续响应，不承诺任意驱动/服务立即取消。
- FFmpeg输出持续排空并只保留64KiB错误尾部；Qwen大请求写管道期间可取消；安装进程有30分钟总时限，取消只回收本任务进程树。最终模型/网络返回后再次核对停止信号，避免停止后仍提交成功结果。运行限制与真实服务边界见[审计](contract-audit.md)。

## C07 本地运行环境、进度与回退

- 环境安装脚本以临时 Python 文件执行校验，成功/失败均清理；`-VerifyOnly` 仅校验已有 Python 与模型依赖，不下载或安装依赖。校验通过后写入就绪标记。

- 源码 Qwen 环境优先显式 `NANFENG_QWEN_PYTHON`，否则 `.runtime/qwen`；冻结版在用户级 `NanfengTranscriber/runtimes/qwen`。冻结版默认需要 `runtime.ready`，显式覆盖保留现有例外。
- 主安装包不含 Torch/CUDA 或模型权重。首次需 Qwen 的冻结任务提示打开安装 BAT；完成后用户再次点击开始。嵌入 Python 3.13.3、Torch 2.11.0 cu128、其余版本见 `requirements-qwen.txt`。
- 默认模型缓存 `%LOCALAPPDATA%/NanfengTranscriber/models`，`NANFENG_TRANSCRIBER_MODEL_DIR` 可覆盖。成功后优先本地；损坏/缺失时可联网修复。升级不删除或复制旧缓存。
- Whisper：CUDA float16 / CPU int8；批量按 8→4→2→普通 GPU 降级，只有明确 GPU 运行库错误回退 CPU。GPU 批量不传中文 initial_prompt。非 GPU 媒体/业务错误不吞成 CPU 回退。
- Qwen：CUDA 不可用时显式通知并用 CPU；不承诺所有 CUDA/OOM 异常都自动回退。识别按最多 30 秒块及低能量边界处理；字幕失败明确报错。日语精确对齐额外分词依赖未验收。
- DLL 预检查和实际运行时共用探测；文件存在仅是预检查，真实 GPU 成功仍以推理结果为准。冻结版不扫描外部 Python 的 NVIDIA 包。
- 真实阶段包括等待、提取、下载、加载、转写、字幕对齐、润色及完成/失败/无文字/已停止/已存在。字幕对齐纳入总进度聚合；不同阶段可以重置阶段进度，不承诺全阶段单调。

## C08 文本联网与诊断

- 本地识别/对齐不上传音频。可选润色通过 `NANZHU_TEXT_API_KEY` 优先、`OPENAI_API_KEY` 备用调用文本 API；发送识别文本和源文件标题，不发送音视频文件。
- 未配置 Key 默认关闭；用户保存或手动开启却无 Key 时阻止 GUI 启动并提示，不静默假装润色成功。
- 默认文本服务地址/模型及 120 秒超时由 `app/postprocess.py` 定义，环境变量可覆盖。鉴权、网络、超时、空响应和格式错误提供中文说明，不回显 Key 或服务端原始响应。
- 运行日志是诊断辅助，写日志失败不改变转写；日志、用户路径、模型、测试音频和凭据均不作发布附件。

## C09 转写历史

- 批量删除复用历史卡片的圆圈状态位作为可勾选控件，不另加方形复选框；未选为空圈、选中为蓝色勾圈。选择模式下卡片、标题和预览图点击切换同一选择状态，全选/取消保持同步；退出选择模式恢复完成状态图标。删除仍需确认且不删除原媒体或外部导出。

- 文稿阅读样式由 `DocumentEditor` 拥有：15px 正文字体、轻微绝对字距、1.7 倍行距、10px 段落间距与自适应阅读栏。仅改变显示格式，不插入空格/换行、不修改保存或导出文字，初始排版不产生撤销记录；视口变化后重新计算自动换行宽度，文档内部保留 16px 留白，使行尾字形和光标避开视口裁切边界。

- 文稿页面按用户要求去掉“当前文稿/转写原文/初始成稿”页签，直接展示可编辑稿；原文与初始成稿仍在数据库独立保存，编辑不会覆盖它们。历史卡片的勾号和完成时间紧凑成组，与 78px 预览图共享垂直中心。旧版整块信息删除反馈已撤回，当前精简标题栏保留。

- 历史卡片采用三行信息：单行标题、单行转写摘要、单行属性。摘要超长省略，不因换行撑高卡片；模式与语言为中性浅灰标签配蓝/紫文字，时长青色、实际模型蓝色且可省略，完整模型可悬停或从转写信息查看。文稿内容不截断保存。

- 文稿详情标题区与外层灰底统一，左侧为原文件核对入口，右侧叉号沿用未保存确认后返回历史，单行文件名仅出现一次、超长省略并可悬停读全；摘要仅含模式、语言、时长和完成时间。完整模型、源路径、导出路径保留在更多菜单的“转写信息”，文件定位亦从该菜单进入；详情菜单不重复已有复制/播放动作。保存与导出结果单独简短反馈，完整导出路径保留在悬停提示及转写信息。

- 历史页同类控件使用统一胶囊与线性图标：中性底色、蓝色返回/筛选、暖红删除、紫色复制/定位、青色播放核对；三个点按钮为 36×36 正圆，默认透明、悬停/焦点同轮廓灰底，无额外方框。更多菜单白底圆角、按触发按钮定位，带语义图标与分组。
- 按用户特别指定，核对页当前字幕使用浅橙底、深橙文字与橙色左标记；未选中片段白底，不将橙色扩散到其他列表。共享矢量图标由 `app/ui_icons.py` 读取并按高 DPI 渲染。

- 设置上方“历史”切换整个右侧页面；返回转写保留现有工作台实例、队列、Worker 与进度。历史页可查看后台进度，不中断转写。
- `app/history.py` 唯一拥有 SQLite 历史库，正式路径 `%LOCALAPPDATA%/NanfengTranscriber/history/history.sqlite3`，数据库版本 1。显式传入 QSettings 的 QA/测试窗口使用该设置文件旁的隔离历史目录。
- 转写成功结果包含任务 ID、源路径、模式与模型、语言、媒体时长、原始时间片段、原文和初始成稿。完成事件按 ID 幂等入库；主动重新转写生成新 ID。失败/停止不冒充成功历史，历史保存失败保留导出结果并在入口明确提示，进入历史时可重试。
- 原文、初始成稿和编辑稿分开保存。日期按完成时间分组倒序，编辑不改变完成时间。搜索覆盖文件名、原文、初始成稿和编辑稿；时间筛选为全部、今天、近 7/30 天。默认读取 100 条，可加载更多；筛选变化清空旧批量选择。
- 文稿与源媒体/外部导出文件独立；文件移动不使文稿失效。可重新定位原媒体、定位已有导出、编辑/复制及再次导出 TXT/Markdown/SRT/DOCX；历史导出复用转写端写入器，并先写临时文件再原子替换目标。
- SRT 与核对页使用同一套原始片段分句规则；编辑稿不伪造时间戳。字幕仅在对应时间范围显示。缩略图后台按需生成，最多两项并发；退出时取消本页拥有的生成进程。原媒体不复制进历史库。
- 删除及清理需确认，仅删除数据库记录和内部缩略图。源媒体、外部导出和模型缓存绝不删除。时间片段损坏但文字可读时仍保留文稿，不列入失效清理；数据库不可读时提示错误，不将其冒充空库。
- 旧版本未保存的任务不自动扫描导出目录补造历史。用户已要求移除“功能审阅”，本功能不恢复该区。

## C10 播放器与字幕

- 原文件核对的画面、标题、字幕与播放控件由 `app/media_player.py` 统一拥有；播放/暂停、点击/拖动进度、时间、10 秒快退/快进、音量/静音、0.5–2× 倍速、字幕开关、全屏均在视频区域内。右侧保留字幕列表，单击跳转，仍使用同一字幕时间真相。当前条目默认垂直居中，手动滚动停止 4 秒后恢复；进度拖动合并为每 75ms 最新解码目标，松手立即应用最终位置。字幕在控制栏上方固定，文字阴影按文字/尺寸/DPI 缓存为柔和渐变，背景透明，同一句字幕不重复排版。
- 参考南枫下载 Android 内置播放器源码（`6d7245e`）：播放中控件 2.5 秒自动隐藏，暂停/鼠标移动重新显示；单击切换控件，双击左侧 30% 快退 10 秒、中间 40% 播放/暂停、右侧 30% 快进 10 秒；范围随播放器宽度适配，600ms 内同侧连续单击累加反馈，跨区或中间双击结束累加；缓冲延迟 350ms 显示。此处只定义本项目行为，不据其他项目参考提交推断其当前功能。
- 桌面键盘：空格播放/暂停、左右键跳转、上下键音量、M 静音、C 字幕、F 全屏、Esc 还原。全屏保留同一播放器实例；关闭全屏窗口还原嵌入状态，关闭画面内播放入口返回历史并停止播放。
- 每个源文件的续播位置用路径哈希写入历史目录内 `playback.ini`，不改历史文稿数据库；只在媒体就绪后保存，结束归零，离开先记录最新位置再停止；位置和音量通过单一后台写者合并落盘，暂停、跳转和关闭不在界面线程同步写盘，未加载/失败媒体不能覆盖原书签。窄窗口收起次要控件，主要操作保留；音频复用同套控件与占位画面。

## C11 界面与平台

- 队列外轮廓、裁切和整块浅灰表头底色由 `QueuePanel` 唯一拥有；表格零内边距贴合，列头透明且不独立设置圆角。顶部右侧空余区与滚动条上方沿用相同底色，表格及其交互内容不得越过共享轮廓。

- 浅灰页面底、无描边白色分区、浅灰输入；彩色按钮保留蓝色主操作、浅橙/浅紫导入和红色停止。绿色仅用于成功等真实状态语义。
- 控件反馈服从同一轮廓；开关鼠标焦点无额外外圈，键盘焦点可见；下拉框再次点触发处关闭，Esc/选择关闭。布局不借整理重设计。
- 自有图标/箭头归 `app/assets`；外部成熟资源授权保留。当前软件仅验收 Windows，Mac 提示是规划，不能据跨平台分支宣称已支持 macOS。

## C12 构建、发布与验证

- 当前构建 `scripts/build_windows_app.ps1`，固定 `build` 与 `dist_release_current`，隔离 PATH 防止外来 ICU DLL。FFmpeg 是已声明的外部构建输入。
- Inno 从冻结版 product.json 读取版本并与源码/显式参数比对，缺失或错配即停止；版本不能悄悄默认 1.0.0。只读 `-ValidateOnly` 可在编译前检查。
- 正式资产名 `NanfengTranscriber-Windows-v<version>-Setup.exe`，只发布一个 Setup EXE，不另附 ZIP/TXT/截图；SHA-256 记录于仓库收据及远端资产摘要。Windows 默认未签名，实际状态如实披露。README 展示当前真实截图，Release 不展示截图。
- 最终 README、元数据和收据更新后再运行 `tools/check_project_contracts.py`、完整测试、相关构建/安装检查。冻结最终文件后记录字节和 SHA-256，若重建需重新验证；远端核对标签提交、发布状态、文件名/大小/摘要。
- 验证等级分别是源码/自动测试、冻结版、隔离安装、真实媒体/API和发布。历史测试计数和截图不是当前通过证明。已发布收据不可由源码整理覆盖改写。
