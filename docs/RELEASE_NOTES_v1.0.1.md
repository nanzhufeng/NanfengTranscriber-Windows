# 南枫转写 Windows v1.0.1

## 本次更新

- 记住保存位置、模型、语言、GPU/CPU 模式、导出格式与翻译润色设置，重启软件后自动恢复。
- 列表增加“定位”操作：优先定位实际导出文件，尚未导出时定位源音视频文件。
- 批次结束后显示中文结果摘要，按成功、失败、跳过、停止分别统计并使用不同颜色提示。
- 修复已有导出结果选择“否（跳过）”后未继续执行剩余任务的问题。
- 继续使用 Inno Setup 生成 Windows 可点击安装包，安装说明中文优先。

## 安装

下载 `NanfengTranscriber_Windows_v1.0.1_Setup_*.zip`，解压后双击其中的 `Setup_*.exe` 安装。首次使用某个模型需要联网下载；模型会保存在本机缓存，后续启动自动复用。

## 已验证

- 源码回归测试 31 项通过。
- 多 DPI 截图基线覆盖 100%、125%、150%、200%。
- PyInstaller 目录版与 Inno 安装包将在本次发布构建中进行启动、静默安装和卸载验证。
