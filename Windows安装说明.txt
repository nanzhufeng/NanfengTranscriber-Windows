南枫转写 Windows 运行说明

推荐从 GitHub Release 下载 NanfengTranscriber-Windows-v1.0.7-Setup.exe，双击安装。当前默认未签名，Windows 可能提示未知发布者。
若使用 PyInstaller 应用目录，双击南枫转写.exe，必须保留整个目录和 _internal，不要只移动 EXE。

软件支持中文精确与通用快速。主包不含模型权重或大型 Torch/CUDA 环境；首次使用中文精确或精确字幕会提示安装独立环境，完成后再次开始。下载完成后复用本机缓存。
输出到软件指定目录，或在设置选择视频所在目录；默认不创建视频子目录。
已有选中格式文件时可选择覆盖，或跳过该项目并继续队列。
支持 TXT、Markdown、SRT、DOCX；可选联网润色只发送文本和文件标题，不上传音视频。

最新安装方法与当前截图以 README.md 为准；旧 IExpress/ZIP 说明是历史兼容记录，不是当前正式发布方式。
